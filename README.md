# UNWRITTEN

PC 웹 브라우저를 목표로 개발하는 2D 포인트 앤 클릭 미스터리·추리 게임입니다. 1인 개발 프로젝트로, AI 코딩 에이전트를 활용합니다.

## 기술 스택

- 엔진: Godot 4.7.2
- 언어: GDScript
- 렌더러: Compatibility
- 기준 해상도: 1280×720
- 목표 플랫폼: PC 웹 브라우저

## 현재 개발 상태

Milestone 01 영산포 조사 프로토타입을 구현했습니다. 기존 청회색 배경 위에 도형으로 만든 임시 목선을 배치했습니다.

- 목선 호버 시 흰색 테두리 표시, 클릭 시 하단 조사 문구 표시
- 최초 조사 시 단서 획득 및 중복 획득 방지
- 단서 목록 열기·닫기, 빈 목록 안내, 단서 이름·설명 표시
- `data/investigation.json`에 단서와 조사 문구 정의, 획득 ID는 메모리에 별도 관리

실제 배경·목선 아트와 저장·불러오기는 아직 없습니다. 증거 조합, 추론 보드, 단계별 힌트, 선택형 AI 조사 보조관은 미구현입니다. 웹 내보내기 설정과 브라우저 실행 검증도 아직 완료되지 않았습니다.

## 실행 방법

1. Godot 4.7.2를 설치하고 프로젝트 관리자에서 이 폴더의 `project.godot`을 가져옵니다.
2. 프로젝트를 에디터에서 엽니다.
3. `main.tscn`을 열고 **현재 씬 실행(F6)** 을 선택합니다.

현재 기본 실행 씬은 지정되어 있지 않으므로 F6으로 씬을 실행합니다. 우측 상단의 단서 목록을 열어 빈 상태를 확인한 다음, 중앙 목선을 조사하고 목록에서 획득한 단서를 확인할 수 있습니다. 실행을 종료하면 획득 상태는 초기화됩니다.

## 자동 검사

Godot 실행 파일 경로를 지정해 다음 명령을 실행합니다. 입력·데이터 검사는 headless 환경에서 마우스 이벤트를 전달하며, 화면의 시각적 품질과 실제 브라우저 플레이는 별도 확인이 필요합니다.

```powershell
& '<Godot 콘솔 실행 파일 경로>' --headless --path . --editor --quit
& '<Godot 콘솔 실행 파일 경로>' --headless --path . --script res://tests/investigation_test.gd
```
