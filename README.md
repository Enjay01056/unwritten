# UNWRITTEN

PC 웹 브라우저를 목표로 개발하는 2D 포인트 앤 클릭 미스터리·추리 게임입니다. 1인 개발 프로젝트로, AI 코딩 에이전트를 활용합니다.

## 기술 스택

- 엔진: Godot 4.7.2
- 언어: GDScript
- 렌더러: Compatibility
- 기준 해상도: 1280×720
- 목표 플랫폼: PC 웹 브라우저

## 현재 개발 상태

Milestone 03 데이터 기반 2슬롯 추론 프로토타입을 구현했습니다. 기존 청회색 배경과 아비사(왼쪽), 목선(중앙), 포구의 흔적(오른쪽) 조사를 유지합니다.

- 각 대상 호버 시 독립적인 흰색 테두리 표시, 클릭 시 하단 조사 문구 표시
- 최초 조사 시 단서 획득 및 중복 획득 방지
- 단서 목록 열기·닫기, 빈 목록 안내, 최대 3개 단서의 이름·설명 표시 및 세로 스크롤
- `data/investigation.json`에 단서와 조사 문구 정의, 획득 ID는 메모리에 별도 관리
- 선택적 `category` 지원: 아비사 증언은 `testimony`, 포구의 흔적은 `observation`, 분류가 없는 기존 목선은 `uncategorized`로 처리

- 단서 이름 클릭으로 추론 슬롯 A·B에 배치, 개별 해제·전체 초기화·조합·보드 열기와 닫기
- JSON 기반 순서 무관 조합, 단서 미소비, 중복 추론·미획득 단서·동일 단서 중복 배치 방지
- 일반 단서와 별도로 추론 결과 이름·설명을 줄바꿈·스크롤로 확인
- `data/inference.json`에 결과·규칙·안내 문구를 정의하고, `inference_model.gd`의 판정·상태와 보드 씬·표시 스크립트를 분리

포구의 흔적과 ‘목선과 증언의 연관성’ 추론은 시스템 검증용 임시 콘텐츠이며 사건의 진실이나 후반부 반전을 확정하지 않습니다. 현재 유효한 조합은 오래된 목선 + 아비사의 증언 하나입니다. 입력은 종류(`clue`/`inference`)와 ID로 표현하지만 추론 재조합 규칙과 선택 UI는 아직 추가하지 않았습니다.

최종 D-LINK UI, 실제 이미지 아트, 저장·불러오기, 단계별 힌트, 선택형 AI 조사 보조관은 아직 없습니다. 웹 내보내기 설정과 브라우저 실행 검증도 아직 완료되지 않았습니다.

## 실행 방법

1. Godot 4.7.2를 설치하고 프로젝트 관리자에서 이 폴더의 `project.godot`을 가져옵니다.
2. 프로젝트를 에디터에서 엽니다.
3. `main.tscn`을 열고 **현재 씬 실행(F6)** 을 선택합니다.

현재 기본 실행 씬은 지정되어 있지 않으므로 F6으로 씬을 실행합니다. 우측 상단의 단서 목록을 열어 빈 상태를 확인한 다음, 목록을 닫고 세 대상을 원하는 순서로 조사하세요. 목록에서 획득한 단서를 스크롤해 확인할 수 있습니다. 실행을 종료하면 획득 상태는 초기화됩니다.

추론하려면 단서 목록의 **오래된 목선**, **아비사의 증언** 이름을 차례로 클릭한 뒤 보드의 **조합하기**를 누릅니다. 빈 슬롯 A→B 순서로 배치되며 슬롯 버튼을 클릭하면 해당 선택만 해제됩니다. **슬롯 초기화**는 선택만 비웁니다. 보드는 상단 **추론 보드** 버튼으로 열고 닫으며 결과·메시지는 보드 오른쪽에서 스크롤해 읽습니다. 조합에 실패해도 단서는 사라지지 않고, 획득한 추론도 보드를 닫거나 슬롯을 초기화해도 유지됩니다.

## 자동 검사

Godot 실행 파일 경로를 지정해 다음 명령을 실행합니다. 입력·데이터 검사는 headless 환경에서 마우스 이벤트를 전달하며, 화면의 시각적 품질과 실제 브라우저 플레이는 별도 확인이 필요합니다.

기존 목선·목록 회귀 검사와 함께 세 대상의 데이터·독립 호버, 6가지 조사 순서, 중복 방지, 전체 목록 내용 및 스크롤을 검사합니다.
추론 검사는 정상·역순·실패 조합, 소유권·중복·미소비·초기화, 실제 GUI 입력 연결, 결과 목록·스크롤과 보드의 겹침 여부를 검사합니다.

```powershell
& '<Godot 콘솔 실행 파일 경로>' --headless --path . --editor --quit
& '<Godot 콘솔 실행 파일 경로>' --headless --path . --script res://tests/investigation_test.gd
& '<Godot 콘솔 실행 파일 경로>' --headless --path . --script res://tests/inference_test.gd
```
